# 跨平台薄宿主约束

- 文档应用随 CAF 容器提供。网页与 Tauri 原生宿主只处理文件、元信息、书架、存储、导出与受控桥接；不得把书内业务复制到平台层，不得修改文档原始字节。
- 平台接口唯一入口为 `web/platform.js`。网页保留静态 catalog、文件选择与既有个人存储；原生适配系统文件选择器、应用私有书架与 JSON 持久化。CAF 内容与安装包分开；打包只复制宿主文件，禁止将 `web/books/`、PDF、语料或用户记录打入程序。
- 原生导入分块复制并按文件 SHA-256 去重；Worker 校验成功才写入书架元信息。文档读取协议按哈希寻址，支持范围请求，拒绝任意路径；不得经 JSON IPC 反复传输整个文档。缺少 JSPI 的 WebView 仍有整文件内存回退，须如实说明限制。
- 保持 iframe 沙箱和独立 CSP，原生会话令牌只注入顶层页面。任何书内代码均不得直接获得文件系统或系统调用能力。用户记录按 CAF 根哈希隔离、有限键写入、原子替换；不引入服务器、登录或数据库。
- 同时支持磁盘路径、Android content URI、iOS security-scoped 文件 URL，处理冷启动和运行中打开。桌面按系统规范设置包名，UI 中文保留简体。所有新开文件仍须走完整 CAF 校验，不能以扩展名或头部检查代替。
- 构建顺序：Linux 实际验证 → Windows／macOS 桌面包 → Android 调试 APK → iOS 模拟器 App。CI 只手动触发且不发布；没有目标系统、SDK、签名或实机时明确记录未验证，不冒称已构建或已发布。
- 验收使用小型独立夹具，覆盖原生运行、WASM、资源 Range、沙箱／网络／原生权限拒绝、应用重开后个人数据保持，以及网页打开关闭、书架与存储隔离回归。构建命令见 README 的构建与运行部分。
