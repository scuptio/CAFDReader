# Terminology — CAFD Reading

> English | [简体中文](../zh-CN/terminology.md)

The English–Chinese glossary for CAFD reading documents. Follow it when writing or
translating documentation so both languages stay consistent. CAF container terms are
defined in the CAF repository's
[doc/spec/terminology.md](https://github.com/scuptio/caf/blob/main/doc/spec/terminology.md).

| English | 中文 | Notes |
|---|---|---|
| interactive document | 交互文档 | CAFD, `.cafd` |
| thin host | 薄宿主 | the reader role |
| reading profile | 阅读 profile | `caf:doc@1` |
| app protocol | 应用协议 | `caf:doc-web@1` |
| bridge | 桥接 | the controlled channel the host offers to in-document apps |
| bookshelf | 书架 | synonym of document shelf; the UI uses "书架" |
| fixture | 夹具 | minimal document used in tests |
| entry | 入口 | the HTML entry of an app manifest |
| mount | 挂载 | mounting of an in-document app |
