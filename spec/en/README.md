# CAFD Specifications

> English | [简体中文](../zh-CN/README.md)

The current specification is **1.0.0-draft.1 (unstable draft)**. It is not finalized and does not promise backward compatibility between drafts; fields, component names, worlds, ABI, and protocol conventions may change. Program and specification versions are maintained independently.

Reading order:

1. [CAFD.md](CAFD.md) — the CAFD document convention: container scope, reading profile, identifiers, versioning and compatibility.
2. [cafd-web-v1.md](cafd-web-v1.md) — the `caf:doc-web@1` app bridge protocol: handshake, capability boundaries, resource and storage limits.
3. [cafd.wit](../cafd.wit) — the `caf:doc@1` data interface implemented by documents.
4. [version.json](../version.json) — the current spec version record.

CAFD reading terminology is defined in [terminology.md](terminology.md); CAF container terms follow the CAF repository's [doc/spec/terminology.md](https://github.com/scuptio/caf/blob/main/doc/spec/terminology.md).
