# 术语表 — CAFD 阅读

> [English](../en/terminology.md) | 简体中文

CAFD 阅读文档的英中术语对照。新增或翻译文档时以此为准，保持双语一致。CAF 容器术语见
CAF 仓库的
[doc/spec/terminology.md](https://github.com/scuptio/caf/blob/main/doc/spec/terminology.md)。

| English | 中文 | 说明 |
|---|---|---|
| interactive document | 交互文档 | CAFD，`.cafd` |
| thin host | 薄宿主 | 阅读器角色 |
| reading profile | 阅读 profile | `caf:doc@1` |
| app protocol | 应用协议 | `caf:doc-web@1` |
| bridge | 桥接 | 宿主向书内应用提供的受控通道 |
| bookshelf | 书架 | 文档架同义，UI 用“书架” |
| fixture | 夹具 | 测试用最小文档 |
| entry | 入口 | 应用清单的 HTML 入口 |
| mount | 挂载 | 书内应用的挂载 |
