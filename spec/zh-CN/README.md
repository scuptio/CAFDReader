> [English](../en/README.md) | 简体中文

当前规范为 **1.0.0-draft.1（不稳定草案）**，尚未定版，不承诺草案之间向后兼容；字段、组件名、world、ABI 和协议约定仍可能调整。程序版本与规范版本独立维护。

3. [cafd.wit](../cafd.wit) —— 文档实现的 `caf:doc@1` 数据接口。
4. [version.json](../version.json) —— 当前规范版本记录。
